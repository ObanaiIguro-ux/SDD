# AI-Powered Skin Disease Detection

A premium, deep learning-fueled web platform layout for detecting skin diseases. This platform allows users to securely upload dermal imagery via an interactive UI, preparing diagnostic data for backend Convolutional Neural Networks (CNNs). 

## 🚀 Quick Start Guide

Follow these simple steps to run this platform locally on your own machine exactly as it was designed.

### Prerequisites
Before you start, make sure you have **Node.js** installed on your computer. If you don't have it, download it for free from [nodejs.org](https://nodejs.org/).

### Installation & Setup

**1. Download the Repository**
Click the green **Code** button at the top of this repository and select **Download ZIP**, then extract the folder. (Alternatively, run `git clone` if you use the terminal).
   
**2. Open your Terminal**
- **Windows:** Open the unzipped folder, click on the folder path address bar at the very top, type `cmd`, and hit Enter.
- **Mac / VS Code:** Open the unzipped folder in VS Code, go to the top menu, and select **Terminal > New Terminal**.

**3. Install Dependencies**
In the terminal window, type the following command and press Enter. This will automatically download all required background packages (React, Framer Motion, Tailwind CSS, Lucide Icons):
```bash
npm install
```

**4. Start the Application**
Once the installation finishes, type this final command to boot up the website:
```bash
npm run dev
```

**5. View the Live Site**
The terminal will generate a local network link (it will look like `http://localhost:5173/`). **Hold Ctrl (or Cmd on Mac) and click the link** to instantly open the live, animated platform in your browser!

## 🛠 Technology Architecture
- **Environment:** Node.js + Vite
- **UI Framework:** React
- **Styling:** Tailwind CSS
- **Interactions:** Framer Motion
- **Icons:** Lucide-React 

*Note: This project serves as a highly optimized Frontend UX/UI flow designed to seamlessly link up with a Python-based deep learning backend (Django/Flask) utilizing OpenCV and TensorFlow models.*
